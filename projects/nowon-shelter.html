PROJECT 01

노원구 재난 대피소 최적 입지선정

서울특별시 노원구를 대상으로 GIS와 다기준 의사결정분석(MCDA)을 활용하여 재난 대피소의 최적 입지를 선정한 공간분석 프로젝트입니다.

1. 프로젝트 개요

재난 발생 시 주민들이 신속하고 안전하게 접근할 수 있는 대피소의 위치는 매우 중요합니다.

본 프로젝트에서는 노원구의 다양한 공간 데이터를 활용하여 재난 대피소 입지에 영향을 미치는 여러 평가기준을 분석하고, 이를 종합하여 최적 후보지를 도출하였습니다.

2. 분석 대상 지역

분석 대상 지역은 서울특별시 노원구이며, 행정구역 경계를 기준으로 공간 데이터를 구축하고 분석을 수행하였습니다.

3. 분석 방법

본 프로젝트에서는 GIS 기반 다기준 의사결정분석 (MCDA, Multi-Criteria Decision Analysis)을 활용했습니다.

서로 다른 공간 데이터를 동일한 기준으로 비교하기 위해 정규화를 수행하고, 각 평가기준에 가중치를 적용한 뒤 WLC 방식으로 최종 적합도 점수를 산출했습니다.

4. 데이터 전처리

분석 과정에서 결측치(NULL)를 확인하고, 필요한 경우 값의 형식을 변환하여 공간분석에 사용할 수 있도록 데이터를 정리했습니다.

또한 분석 대상 데이터의 공간 범위가 노원구 경계와 일치하도록 필요한 지오프로세싱 과정을 수행했습니다.

5. 정규화

각 평가기준은 단위와 값의 범위가 서로 다르기 때문에 Min-Max 정규화를 활용하여 0에서 1 사이의 값으로 변환했습니다.

또한 평가기준의 성격에 따라 편익 기준과 비용 기준을 구분하여 정규화 방향을 다르게 적용했습니다.

6. 가중치 적용 및 WLC

각 평가기준의 상대적인 중요도를 반영하기 위해 가중치를 부여했습니다.

이후 정규화된 각 평가기준 값에 가중치를 곱하고 합산하는 WLC(Weighted Linear Combination) 방식을 활용하여 종합 적합도 점수를 산출했습니다.

7. 제약조건 적용

실제 대피소 설치가 불가능하거나 적절하지 않은 지역을 제외하기 위해 Boolean Constraint 방식을 활용했습니다.

후보 가능 지역은 1, 제외 지역은 0으로 설정한 뒤 적합도 결과와 결합하여 최종 후보지를 추출했습니다.

8. 적합도 등급화

최종 적합도 결과는 Jenks Natural Breaks 방법을 활용하여 여러 등급으로 분류했습니다.

이를 통해 상대적으로 높은 적합도를 보이는 지역을 시각적으로 구분하고 최종 후보지를 선정했습니다.

9. 분석 흐름

데이터 수집 → 결측치 및 데이터 형식 확인 → 공간 범위 정리 → 평가기준별 정규화 → 가중치 적용 → WLC → 제약조건 적용 → 적합도 등급화 → 최종 후보지 선정

10. 프로젝트 결과

여러 평가기준을 종합하여 노원구 내 재난 대피소 설치에 상대적으로 적합한 지역을 도출했습니다.

단일 공간지표만을 활용하는 것이 아니라, 여러 기준을 정규화하고 가중치를 적용하여 종합적으로 평가함으로써 보다 체계적인 입지선정 과정을 구현했습니다.

11. 프로젝트를 통해 학습한 내용

GIS-MCDA 기반 입지 적합성 분석의 전체 과정과 QGIS를 활용한 데이터 전처리, 정규화, 가중합, 제약조건 적용 및 공간 시각화 방법을 학습했습니다.
